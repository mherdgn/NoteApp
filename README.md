# 📝 NoteApp

NoteApp, kullanıcıların kişisel notlarını oluşturmasını, düzenlemesini, silmesini ve favorilerine eklemesini sağlayan web tabanlı bir not yönetim uygulamasıdır.

## ✨ Özellikler

- Kullanıcı girişi ve oturum yönetimi
- Not oluşturma, düzenleme ve silme
- Notları favorilere ekleme ve favorilerden çıkarma
- Kullanıcıya özel not yönetimi
- Zengin metin düzenleme desteği
- Karanlık ve aydınlık tema
- İşlem bildirimleri

## 🛠️ Kullanılan Teknolojiler

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server
- HTML, CSS ve JavaScript
- Bootstrap

## ⚙️ Kurulum

1. Projeyi bilgisayarınıza indirin veya klonlayın.
2. Projeyi Visual Studio ile açın.
3. `appsettings.json` dosyasındaki veritabanı bağlantısını kendi SQL Server ortamınıza göre düzenleyin.
4. Gerekli veritabanı migration işlemlerini uygulayın.
5. Projeyi Visual Studio üzerinden çalıştırın.

## 🗄️ Veritabanı

Uygulama Microsoft SQL Server kullanır. Veritabanı bağlantı ayarları `appsettings.json` dosyasında yapılandırılır.
